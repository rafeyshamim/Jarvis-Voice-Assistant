# Jarvis Voice Assistant

Jarvis is a voice-controlled assistant built using Python. It leverages libraries like `speech_recognition`, `pyttsx3`, and `google.genai` to listen to commands, process them, and respond accordingly. This project demonstrates basic functionalities such as speech recognition, web browsing, and integration with AI models for content generation.

## Features

- **Voice Interaction:** Jarvis listens to the user's voice commands using the microphone.
- **Speech Output:** It responds to the user with a voice message using the `pyttsx3` library.
- **Web Browsing:** Jarvis can open web pages based on specific commands.
- **AI Content Generation:** Jarvis interacts with the `genai` API to generate AI-driven responses.
  
## Requirements

To run this project, you'll need to install the following dependencies:

- `speech_recognition`: For recognizing and transcribing speech to text.
- `pyttsx3`: For text-to-speech synthesis (speech output).
- `google-genai`: For AI-based content generation.
- `webbrowser`: To open URLs in the web browser.

### Installing the dependencies

To install the necessary Python packages, run the following command to install all dependencies:
command:

pip install -r requirements.txt
